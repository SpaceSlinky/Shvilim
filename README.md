# שבילים: ניווט אופליין במסלולי הליכה

אפליקציית Web (PWA) לאנדרואיד. היא מציגה מפה וקטורית עם שבילים מסומנים בצבעים ושמות בעברית, את המיקום שלכם ב-GPS, ואת המיקום ביחס למסלול GPX. אחרי הורדה אחת היא עובדת בלי אינטרנט.
אין שרת, אין הרשמה ואין תשלום. כל ההורדות מתבצעות ישירות מהטלפון.

## התקנה (פעם אחת)

### 1. אירוח הקבצים (בחינם)
GPS והתקנת PWA עובדים רק מכתובת HTTPS, ולכן צריך להעלות את הקבצים פעם אחת לאתר סטטי:

**GitHub Pages:**
1. יוצרים מאגר ציבורי חדש ב-GitHub.
2. ‏Add file ← Upload files ← גוררים את **כל הקבצים** שבתיקייה ← Commit.
3. ‏Settings ← Pages ← Branch: `main`, תיקייה `/ (root)` ← Save.
4. אחרי כדקה האפליקציה זמינה בכתובת `https://<שם-משתמש>.github.io/<שם-המאגר>/`.

### 2. בטלפון
1. פותחים את הכתובת ב-**Chrome**, עם אינטרנט.
2. לוחצים **"הורד את מפת הכרמל"** וממתינים כחצי דקה.
3. בתפריט של Chrome (⋮) בוחרים **"הוספה למסך הבית"**, ומאשרים הרשאת מיקום.

מעכשיו אפשר לפתוח את האפליקציה גם במצב טיסה.

## מה יש במפה
- **שבילים מסומנים** בצבע הסימון שלהם (אדום, כחול, ירוק, שחור…) עם שם השביל.
- דרכים, דרכי עפר (קו חום מקווקו), שבילים לא מסומנים (קו כהה מקווקו) ונחלים.
- פסגות עם הגובה שלהן, מעיינות, תצפיות, חורבות ויישובים.
- המסלול שלכם מוצג כפס ורוד רחב ושקוף עם חצי כיוון, כך שצבע הסימון נשאר גלוי.

## שימוש
| כפתור | פעולה |
|---|---|
| 🧭 | מצפן. הקשה מסובבת את המפה לפי הכיוון שהטלפון מצביע אליו, והקשה נוספת מחזירה צפון למעלה. אפשר גם לסובב בשתי אצבעות. |
| ◇ | שכבות. בחירת רקע (וקטורי אופליין, טופוגרפי עם קווי גובה, מפת ישראל להליכה או תצלום אוויר, השלושה האחרונים דורשים אינטרנט) והדלקה או כיבוי של שבילים, דרכים, נחלים, נקודות עניין ושמות. |
| 🔍 | חיפוש מקום: שביל, נחל, פסגה, מעיין, יישוב או אזור שסימנתם. עובד גם בלי אינטרנט. "חפש" במקלדת מחפש גם באינטרנט. |
| ◎ | GPS ומעקב אחרי המיקום (כחול = במעקב). גרירת המפה מפסיקה את המעקב. **לחיצה ארוכה מכבה את ה-GPS.** |
| ⤴ | טעינת קובץ GPX. המסלול נשמר גם אחרי סגירת האפליקציה. |
| ⛶ | התמקדות בכל המסלול |
| ☰ | הסרת מסלול, הורדת אזור אחר, עדכון המפה, השארת המסך דולק |

**שורת המצב:**
- **מהמסלול:** המרחק מהמסלול. ירוק = על המסלול, כתום = עד 100 מ', אדום = סטייה.
- **עברת / נותרו:** המרחק שעברתם לאורך המסלול והמרחק שנשאר.

**סימון אזור:** בתפריט ☰ בוחרים "סמן אזור חדש", מקישים על המפה סביב האזור (3 נקודות לפחות), לוחצים "סיום" ונותנים לאזור שם. האזור מוצג במסגרת כתומה ומופיע בחיפוש. ב"האזורים שלי" אפשר להציג אותו, להוריד לו מפה אופליין או למחוק אותו.

**אזור נוסף:** מזיזים את המפה ובוחרים בתפריט "הוסף למפה השמורה את האזור שבמסך". האזור מתווסף למה שכבר שמור.

**מצב לילה:** בתפריט ☰. בהתחלה האפליקציה עוקבת אחרי הגדרת המצב הכהה של הטלפון.

**עדכונים:** אוטומטיים. כשיש גרסה חדשה, האפליקציה מתעדכנת בפתיחה הבאה עם אינטרנט, והמפה והמסלולים נשמרים.
